# Basic Terminal Commands

## 1. pwd

`pwd` stands for **Print Working Directory**.

It displays the current working directory and tells us where we are currently working.

### Syntax
`pwd`

### Example
`pwd`

### Important Point
`pwd` helps us understand our current location in the file system.

---

## 2. ls

`ls` is used to list the files and directories present in the current directory.

### Syntax
`ls`

### Example
`ls`

### Important Point
`ls` shows the contents of the current directory.

---

## 3. clear

`clear` is used to clear the visible content of the terminal screen.

### Syntax
`clear`

### Example
`clear`

### Important Point
`clear` only clears the visible terminal screen. It does not delete files or folders.

---

## 4. mkdir

`mkdir` stands for **Make Directory**.

It is used to create a new directory (folder).

### Syntax
`mkdir directory-name`

### Example
`mkdir projects`

This creates a directory named `projects`.

### Important Point
`mkdir` is used to create new folders from the terminal.

---

## 5. touch

`touch` is used to create a new empty file.

### Syntax
`touch file-name`

### Example
`touch notes.txt`

This creates a new empty file named `notes.txt`.

### Important Point
`touch` is commonly used to create files from the terminal.

---

## 6. rm

`rm` stands for **Remove**.

It is used to delete a file.

### Syntax
`rm file-name`

### Example
`rm notes.txt`

This removes the `notes.txt` file.

### Important Point
Be careful when using `rm` because the deleted file may not be moved to the Recycle Bin.

---

## 7. echo

`echo` is used to display text in the terminal.

### Syntax
`echo "text"`

### Example
`echo "Hello World"`

### Output
Hello World

### Important Point
`echo` is useful for displaying text and working with simple text output.

---

## 8. history

`history` is used to display commands that were previously executed in the terminal.

### Syntax
`history`

### Example
`history`

### Important Point
`history` is useful for reviewing commands that we have previously used.

---
