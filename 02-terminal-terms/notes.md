# Different Terms Related to Terminal

## 1. Command Line

A command line is a text-based interface where we type commands to interact with the computer.

## 2. Terminal

A terminal is an application that provides an interface to interact with the computer using commands.

## 3. Console

A console is an interface through which we can interact with the operating system or a program using commands.

## 4. Shell

A shell is a program that interprets the commands we type and tells the operating system what to do.

## 5. Bash

Bash stands for **Bourne Again SHell**.

It is a popular Unix shell and is commonly used in Linux and macOS environments.

## 6. Z Shell (Zsh)

Zsh stands for **Z Shell**.

It is a Unix shell that provides features such as improved command-line interaction and customization.

## Important Point

Command Line, Terminal, Console, Shell, Bash, and Zsh are related terms, but they do not mean exactly the same thing.
