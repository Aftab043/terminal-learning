# What is the Terminal?

A terminal is a text-based interface that allows us to interact with the computer by typing commands.

Instead of using a Graphical User Interface (GUI), we can perform tasks directly by entering commands.

## Why do we use a Terminal?

We can use the terminal to:

- Create files and folders
- Delete files and folders
- Navigate between directories
- Run programs and scripts
- Install software and packages
- Manage and automate tasks

## Terminal vs GUI

### GUI
- Uses buttons, icons, and menus
- Easy for beginners
- Example: File Explorer

### Terminal
- Uses text commands
- Faster for many tasks
- Useful for developers and system administration

## Important Point

The terminal allows us to communicate with the operating system using commands.
