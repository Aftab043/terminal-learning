# Terminal Installation on Windows

## Git Bash

Git Bash allows us to use Bash and Unix/Linux-style commands on Windows.

## Download

Download Git for Windows from the official website:

[Git for Windows](https://git-scm.com/download/win)

## Installation Steps

1. Go to the official Git website.
2. Download Git for Windows.
3. Run the installer.
4. Continue with the installation using the required options.
5. Complete the installation.
6. Open Git Bash from the Start Menu.

## Verify Installation

Open Git Bash and run:

```bash
git --version
